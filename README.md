> **fit linear models to BIDS datasets**

Wraps FitLins to fit a first-level (run-level) GLM to a preprocessed BOLD run: it generates a BIDS Stats Model from readable settings (condition column, HRF, contrasts, confound strategy), stages a minimal BIDS and derivatives layout with the events and fMRIPrep confounds, and runs FitLins. Use it for single-subject task fMRI activation maps without writing a Stats Model by hand. Inputs should be fMRIPrep outputs in the selected space with a matching events.tsv; group-level analysis is not supported.

## Running the App

### On brainlife.io

Open the App at [doi.org/10.25663/brainlife.app.890](https://doi.org/10.25663/brainlife.app.890), choose `neuro/func/task`, `neuro/func/task`, `neuro/regressors`, `neuro/mask` from your project, set the parameters and press **Execute**. The results are saved to your project as `raw`, `raw`.

### Locally

You need [Singularity/Apptainer](https://apptainer.org/) (the App runs in `poldracklab/fitlins:0.11.0`), [`jq`](https://jqlang.github.io/jq/).

1. Clone this repository.
2. Create `config.json` with the paths to your inputs and the parameters:

   ```json
   {
       "bold": "/path/to/bold/bold",
       "events_tsv": "/path/to/events/events_tsv",
       "confounds_tsv": "/path/to/confounds/confounds_tsv",
       "confounds_json": "/path/to/confounds/confounds_json",
       "brain_mask": "/path/to/brain_mask/brain_mask",
       "repetition_time": 2,
       "design_name": "brainlife_fitlins_model",
       "design_description": "First-level model generated by brainlife FitLins app.",
       "condition_column": "trial_type",
       "include_conditions": "",
       "convolve_conditions": "",
       "hrf_model": "spm",
       "contrasts_json": "",
       "auto_task_vs_baseline": true,
       "auto_dummy_contrasts": true,
       "confounds_strategy": "acompcor6",
       "include_framewise_displacement": true,
       "include_dvars": true,
       "include_cosine_drift_terms": false,
       "confounds_strict": false,
       "fitlins_space": "MNI152NLin2009cAsym",
       "fitlins_desc_label": "preproc",
       "fitlins_estimator": "nilearn",
       "fitlins_drift_model": "cosine",
       "fitlins_n_cpus": 2,
       "fitlins_mem_gb": 8,
       "fitlins_drop_missing": true,
       "dry_run": false,
       "model_json_path": "",
       "subject_label": "",
       "session_label": "",
       "task_label": "",
       "run_label": "",
       "convolve_map_json": ""
   }
   ```

3. Run `./main`.

## Interface Highlights

- `runs[]`: one object per run with `bold`, `events_tsv`, and `confounds_tsv`.
- `design`: readable model controls (`condition_column`, `hrf_model`, and contrast weights by condition name).
- `confounds`: strategy-based nuisance selection (`acompcor6`, `motion_24`, `basic`, `custom`, `none`).
- `advanced.model_json_path`: escape hatch for full manual BIDS Stats Models JSON.

See `config.json.example` for a complete example.

## Scientific Defaults

- First-level run model with `Factor` + `Convolve` transforms on `trial_type` by default.
- Confounds default to `acompcor6` plus motion, FD, and DVARS (dropping missing columns unless `strict: true`).
- App is intentionally first-level only for now (`analysis_level=run`).
